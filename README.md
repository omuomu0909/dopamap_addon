# dopamap — Google Maps で YouTube 動画を見よう！

Google Maps（PCブラウザ）上で、選択した店舗や検索結果一覧に関連する YouTube Shorts および通常動画をマップ上で直接探して再生できる Chrome 拡張機能（Manifest V3）です。

---

## 🌟 主な機能

1. **Google Maps への直接統合**
   - Google Maps 上でピンをクリック、または店舗詳細を開くと自動で店名・地域・カテゴリを抽出。
   - サイドパネルに該当店舗の YouTube Shorts / 通常動画の件数を表示。
2. **フローティング動画プレイヤー**
   - マップから離れることなく、オーバーレイ表示で YouTube 動画を視聴。
   - ドラッグ移動やサイズ変更、前後動画へのスムーズなナビゲーションに対応。
3. **検索結果リストの一括スキャン**
   - Google Maps での検索結果リスト（例:「渋谷 ラーメン」「新宿 居酒屋」など）を自動または手動でスキャン。
   - リスト内の各店舗に動画があるか自動で判定し、見つかった店舗をサイドパネルに一覧化。
4. **投稿者（チャンネル）フィルタ & プリセット**
   - 特定のグルメ系 YouTuber や投稿者の動画に絞り込んで探索可能。
   - よく見る投稿者をプリセットとして保存可能。
5. **API キー不要（スタンドアロン動作）**
   - Google Maps API や YouTube Data API のキー設定不要で手軽に利用可能。

## 📥 インストール方法（CRX ファイルからインストール）

> **最も手軽な方法です。** ビルド環境は不要です。

### 1. CRX ファイルをダウンロード

[Releases ページ](https://github.com/omuomu0909/dopamap_addon/releases) から最新の `dist.crx` をダウンロードします。

### 2. Chrome に手動インストール

1. Google Chrome を開き、アドレスバーに以下を入力して **拡張機能の管理画面** を開きます。
   ```
   chrome://extensions/
   ```
2. 画面右上の **「デベロッパー モード」** を **ON** にします。
3. ダウンロードした **`dist.crx`** ファイルを、この画面に**ドラッグ＆ドロップ**します。
4. 確認ダイアログが表示されたら **「拡張機能を追加」** をクリックします。
5. 拡張機能一覧に **「dopamap: 地図上ですぐ動画を見よう！」** が追加されればインストール完了です。

> ⚠️ Chrome の仕様上、Web Store 外の CRX は「デベロッパーモード ON」が必要です。インストール後はデベロッパーモードを OFF に戻しても動作します。

## 🛠 開発者向け：ソースからビルドして読み込む

Node.js（v18 以上）がインストールされている環境で実行します。

```bash
# リポジトリをクローン
git clone https://github.com/omuomu0909/dopamap_addon.git
cd dopamap_addon

# 依存パッケージのインストール
npm install

# 拡張機能のビルド
npm run build
```

ビルド後、`chrome://extensions/` を開き **「パッケージ化されていない拡張機能を読み込む」** で `dist/` フォルダを選択します。

## 🚀 使い方

1. **Google Maps を開く**
   - [https://www.google.com/maps](https://www.google.com/maps) にアクセスします。
2. **店舗を探索する**
   - 地図上のピンをクリック、または店舗を検索すると、画面右側に dopamap のサイドパネルが表示されます。
   - 「Shorts」または「通常動画」のボタンを押すとフローティングプレイヤーが起動し、動画が再生されます。
3. **一覧検索を行う**
   - 例えば「銀座 カフェ」と検索すると、左側の店舗リストに対して自動スキャンが動作し、動画が見つかった店舗が右側パネルに集約されます。
4. **拡張機能のアイコンから各種設定**
   - ツールバーの拡張機能アイコンをクリックすると、以下のカスタマイズが可能です。
     - パネルテーマ（ダーク / ライト）
     - よく使う投稿者（チャンネル）のプリセット登録
     - 自動スキャンの ON / OFF
     - 表示件数やスキャン間隔の調整
     - キャッシュのクリア
