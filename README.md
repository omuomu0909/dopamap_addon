# mapshort — Google Maps で YouTube ショート・通常動画を再生する Chrome 拡張機能

Google Maps（PCブラウザ）上で、選択した店舗や検索結果一覧に関連する YouTube Shorts および通常動画をマップ上で直接探して再生できる Chrome 拡張機能（Manifest V3）です。

---

## 🌟 主な機能

1. **Google Maps への直接統合**
   - Google Maps 上でピンをクリック、または店舗詳細を開くと自動で店名・地域・カテゴリを抽出。
   - サイドパネルに該当店舗の YouTube Shorts / 通常動画の件数を表示。
2. **フローティング動画プレイヤー**
   - マップから離れることなく、オーバーレイ表示で YouTube 動画を視聴。
   - ドラッグ移動やサイズ変更、前後動画へのスムーズなナビゲーションに対応。
3. **検索結果リストの一括スキャン**
   - Google Maps での検索結果リスト（例:「渋谷 ラーメン」「新宿 居酒屋」など）を自動または手動でスキャン。
   - リスト内の各店舗に動画があるか自動で判定し、見つかった店舗をサイドパネルに一覧化。
4. **投稿者（チャンネル）フィルタ & プリセット**
   - 特定のグルメ系 YouTuber や投稿者の動画に絞り込んで探索可能。
   - よく見る投稿者をプリセットとして保存可能。
5. **API キー不要（スタンドアロン動作）**
   - Google Maps API や YouTube Data API のキー設定不要で手軽に利用可能。

## 📦 アドオン（拡張機能）の追加方法（インストール手順）

開発者モードを利用して、Google Chrome または Chromium ベースのブラウザ（Edge / Brave など）に追加できます。

### 1. リポジトリのクローン & ビルド

Node.js（v18 以上推奨）がインストールされている環境で実行します。

```bash
# リポジトリをクローン
git clone https://github.com/omuomu0909/dopamap_addon.git
cd dopamap_addon

# 依存パッケージのインストール
npm install

# 拡張機能のビルド
npm run build
```

ビルドが完了すると、プロジェクト直下に `dist/` フォルダが生成されます。
（※リポジトリにビルド済みの `dist/` が含まれている場合は、上記ビルド手順を省略して直接読み込むことも可能です）

---

### 2. Chrome に拡張機能を読み込む

1. Google Chrome を開き、アドレスバーに以下を入力して **拡張機能の管理画面** を開きます。
   ```text
   chrome://extensions/
   ```
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチを **ON** にします。
3. 画面左上に出現する **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. ファイル選択ダイアログが表示されるので、本プロジェクトの **`dist` フォルダ**（`dopamap_addon/dist`）を選択します。
5. 拡張機能一覧に **「mapshort — 地図でショート動画」** が追加されればインストール完了です。

## 🚀 使い方

1. **Google Maps を開く**
   - [Google Maps (https://www.google.com/maps)](https://www.google.com/maps) にアクセスします。
2. **店舗を探索する**
   - 地図上のピンをクリック、または店舗を検索すると、画面右側に mapshort のサイドパネルが表示されます。
   - 「Shorts」または「通常動画」のボタンを押すとフローティングプレイヤーが起動し、動画が再生されます。
3. **一覧検索を行う**
   - 例えば「銀座 カフェ」と検索すると、左側の店舗リストに対して自動スキャンが動作し、動画が見つかった店舗が右側パネルに集約されます。
4. **拡張機能のアイコンから各種設定**
   - ツールバーの拡張機能アイコンをクリックすると、以下のカスタマイズが可能です。
     - パネルテーマ（ダーク / ライト）
     - よく使う投稿者（チャンネル）のプリセット登録
     - 自動スキャンの ON / OFF
     - 表示件数やスキャン間隔の調整
     - キャッシュのクリア
